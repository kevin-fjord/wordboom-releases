## 首次使用

1. 将完整 ZIP 解压到电脑上的可写文件夹。
2. 运行 **WordBoom.exe**。
3. 新用户注册邮箱并完成验证；已有账号直接登录。**无需激活码**。

请选择名为 **WordBoom-v7.0.1-Windows-x64.zip** 的完整包，不要下载 GitHub 自动生成的 Source code 压缩包，也不要直接在 ZIP 内运行程序。

Windows 需要 .NET Framework 4.8 和 Microsoft Edge WebView2 Runtime；如缺少 WebView2，请从[微软官方网站](https://developer.microsoft.com/microsoft-edge/webview2/)安装。完整包包含离线声音、视频组件、词典和可选浏览器插件。
